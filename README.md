# قدم اول (THE FIRST MOVE) — داستان تعاملی سه‌بعدی موبایل

یک بازی داستانی سه‌بعدی تعاملی و سینمایی، طراحی‌شده به‌صورت **کاملاً فارسی (RTL)** با اولویت موبایل افقی (Landscape) در مرورگر (iOS Safari و Android Chrome) با استفاده از **React + TypeScript + Three.js (`@react-three/fiber`) + GSAP + Zustand + Web Audio API**.

## ویژگی‌های نسخه ارتقایافته (نسخه کامل فارسی)

1. **کاملاً فارسی با تایپوگرافی بومی (`Vazirmatn`)**:
   - تمام بخش‌های بازی از صفحه بارگذاری، راهنمای چرخش صفحه، صفحه آغازین («قدم اول»)، پرسش‌نامه ۴ مرحله‌ای شخصیت، پرسش محترمانه وضعیت رابطه، پایان محترمانه، راهنمای مراحل، دکمه‌های لمسی موبایل، منوی تنظیمات و گرافیک، تا دیالوگ‌های چندمرحله‌ای و پایان داستان به‌طور کامل و روان به زبان فارسی پیاده‌سازی شده‌اند.
2. **مدل‌های سه‌بعدی ارتقایافته، موهای کاملاً باز از جلوی چشم‌ها و سیستم احساسات چهره**:
   - بازطراحی مدل‌های `.glb` هر دو شخصیت اصلی و دانشجویان محیطی (`female_character.glb`، `male_character.glb`، `student_npc.glb`، `mission_props.glb`) با مفاصل یکپارچه، جزئیات لباس و فرم طبیعی موها در بالای پیشانی به‌طوری که چشم‌ها، ابروها و **عینک‌های سه‌بعدی واقعی (`Glasses3D`)** کاملاً واضح و بدون پوشیده شدن توسط موها دیده می‌شوند.
   - **سیستم احساسات چهره (`CharacterEmotion`)**: تغییر نرم و زنده حالت ابروها، پلکِ لبخند زیر چشم، سرخی ملایم گونه‌ها (خجالت/صمیمیت) و حالت‌های مختلف دهان (`neutral`، `warm_smile`، `shy`، `curious`، `nervous`، `happy_laugh`، `hopeful`، `thoughtful`).
3. **کارگردانی جدید صحنه‌ی لابی و شروع گفت‌وگو هنگام رفتنِ دختر**:
   - در لابی آفتابی دانشگاه، تمام مدل‌های دیگر دو‌به‌دو روی صندلی‌ها روبه‌روی کناریِ خود نشسته و مشغول گفت‌وگو هستند، **به‌جز شخصیت پسر** که تنها و ساکت روی صندلی نشسته و در فکر فرو رفته است.
   - پس از پایان سکانس سینمایی لابی، وقتی دختر (بازیکن) به سمت درِ خروجی لابی حرکت می‌کند تا برود (چه با جوی‌استیک حرکتی و چه با انتخاب گزینه رفتن به سمت خروجی)، پسر دلش را به دریا می‌زند، از روی صندلی بلند می‌شود، محترمانه جلو می‌آید و گفت‌وگو را آغاز می‌کند.
4. **دیالوگ‌های چندلایه، طبیعی و شخصی‌سازی‌شده**:
   - دیالوگ‌ها متناسب با پاسخ‌های بازیکن در پرسش‌نامه آغازین (ارزش مهم در شروع آشنایی، حال‌وهوای عصر دلخواه و...) شکل می‌گیرند و در تمام مراحل، انتخاب‌های گرم، آرام و یا رد محترمانه بدون هیچ‌گونه فشار عاطفی در اختیار بازیکن قرار دارد.

## اجرای پروژه

```bash
npm install
npm run generate:assets   # ساخت مجدد مدل‌های سه‌بعدی در public/models/
npm run dev               # اجرای سرور توسعه روی پورت 5173
npm run build             # بررسی TypeScript و ساخت نسخه نهایی در dist/
```
