# قدم اول (THE FIRST MOVE)

یک داستان تعاملی سهبعدی و کاملاً فارسی، ساختهشده با **React + TypeScript + Three.js / React Three Fiber + GSAP + Zustand + Web Audio API**.

فضا همان فضای همیشگی بازی مانده است: **دانشگاه، دنیای سردی که آرام رنگ میگیرد، کلاس ۲۰۴، و لابی قبل از در خروجی**. چیزی که از نو نوشته شده، لحن، دیالوگها، جزئیات محیط، رابط کاربری و نحوه اجرا از خود GitHub است.

## بازی را مستقیم از GitHub اجرا کنید

🔗 **آدرس بازی:** <https://axiasoft.github.io/Ghadam-Aval/>

برای اینکه بازی بدون workflow، بدون سرویس جانبی و بدون تنظیم اضافی از همین ریپازیتوری بالا بیاید، **بیلد استاتیک آماده داخل `docs/` کامیت شده است**. فایل `index.html` ریشه فقط به `./docs/index.html` هدایت میکند؛ همان فایلهایی که GitHub Pages از شاخه `main` و مسیر `/` سرو میکند. فایلهای `.nojekyll` هم در ریشه و داخل `docs/` هستند تا Jekyll دست Assets ساختهشده نزند.

مسیرها نسبی هستند (`base: './'` در `vite.config.ts` و `import.meta.env.BASE_URL` در `AssetManager`)، بنابراین مدلها، فونتها و صداها زیر `/Ghadam-Aval/` هم درست لود میشوند.

> بعد از تغییر دادن سورس، کافی است `npm run build` بزنید و پوشه `docs/` تازه را همراه تغییرات کامیت کنید. Pages از فایلهای کامیتشده سرو میکند، نه از `node_modules` یا بیلد لوکال شما. اگر بعداً انتشار خودکار خواستید، میتوانید یک workflow اضافه کنید؛ نسخه فعلی عمداً به Actions وابسته نیست.

## اجرای لوکال

```bash
npm ci
npm run dev        # http://localhost:5173/app.html
npm run build      # بررسی TypeScript + ساخت docs/
npm run preview    # پیشنمایش همان بیلد استاتیک روی :4173
```

روی `localhost`، `index.html` ریشه به `app.html` هدایت میکند و همان سورس TypeScript اجرا میشود. روی Pages، ریشه به `docs/index.html` میرود؛ `npm run preview` هم همان بیلد استاتیک را نشان میدهد.

دستورهای اختیاری برای ساخت مجدد Assets:

```bash
npm run generate:assets   # مدلهای GLB در public/models/
npm run generate:music    # قطعات موسیقی
npm run generate:sfx      # افکتها و همهمه محیط
```

## چه چیزهایی بازنویسی شد؟

- **همه دیالوگها** با لحنی انسانیتر و منطقیتر: گفتوگو با یک دلیل واقعی شروع میشود («یک خط جزوه جا افتاده»)، نه با اعتراف ناگهانی. جملهها کوتاهاند، شخصیتها به پاسخهای قبل توجه میکنند و «نه» گفتن کاملاً محترمانه و بدون فشار است.
- **پسر اسم ندارد.** در تمام برچسبها و متنها فقط «پسر» نوشته میشود؛ هیچ اسم شخصی برای او استفاده نشده است. بازیکن هم «تو» است.
- **شاخههای واقعی گفتوگو:** سه پاسخ اول، سه واکنش میانی و سه پایان (`آره / آرومتر / نهِ محترمانه`). انتخابها `endingVariant` را تنظیم میکنند و تیتراژ نهایی بر همان اساس ساخته میشود.
- **پرسشنامه تبدیل به جزئیات قابل دیدن میشود:** پاسخها روی هدفون، لیوان چای، جای خلوت، لحن پیشنهاد بعدازظهر و حتی خط آخر جزوه اثر میگذارند.
- **دفترچه مشاهدات:** HUD یک برچسب «جزئیات صحنه» و یک دفترچه دارد که گردوغبار در نور، لیوان نیمهپر، بخاری کلاس، خودکار جا مانده و مکث قبل از در را ثبت میکند.
- **لایه اتمسفر سهبعدی سبک:** `AtmosphereField` ذرات گردوغبار و ذرات گرم را با تغییر `worldWarmth` نرم میکند؛ CSS هم vignette، grain و grade سرد/گرم اضافه کرده است.
- **UI کامل RTL:** صفحه شروع، بارگذاری، پرسشنامه، راهنما، منوی توقف، کارت دیالوگ، داک تصمیم آخر و تیتراژ دوباره طراحی شدند؛ تایپرایتر به `prefers-reduced-motion` احترام میگذارد و با Enter/Space هم جلو میرود.
- **تمیزکاری:** رشتههای خراب و ترکیبهای عجیب نسخه قبل حذف شد؛ لاگ پاسخها دیگر داخل `src/` نوشته نمیشود. در لوکال به `.local/playerResponses.json` میرود و روی Pages فقط در `localStorage` میماند، چون سروری وجود ندارد.

## نقشه فایلهای مهم

| فایل | کارش |
| --- | --- |
| `app.html` | قالب Vite برای اجرای سورس روی لوکال |
| `index.html` | هدایتگر ریشه: لوکال → `app.html`، Pages → `docs/index.html` |
| `docs/` | بیلد استاتیک کامیتشده برای GitHub Pages |
| `scripts/finalizePages.mjs` | تبدیل خروجی `app.html` به `docs/index.html` و ساخت `.nojekyll` |
| `src/dialogue/dialogueData.ts` | تکمنبع تمام متنها، پرسشنامه، زیرنویس کاتسینها و گراف دیالوگ |
| `src/narrative/world.ts` | فصلها، زمان/مکان صحنهها و جزئیات محیطی |
| `src/narrative/endings.ts` | تیتراژ متناسب با تصمیم آخر و پاسخهای پرسشنامه |
| `src/dialogue/DialogueOverlay.tsx` | کارت گفتوگو، تایپرایتر، انتخابها و ثبت نتیجه |
| `src/scenes/AtmosphereField.tsx` | گردوغبار، ذرات گرم و لایه نوری سبک |
| `src/styles/global.css` | سیستم طراحی RTL، افکتهای سینمایی و تنظیمات موبایل |

## نکته درباره صدا

صدای مرورگر بعد از اولین لمس/کلیک آزاد میشود. هشت قطعه موسیقی و افکتهای محیطی همانند قبل در `src/audio/` هستند؛ فقط توضیح حالوهوایشان به چیزهایی که واقعاً در صحنه دیده میشود تغییر کرده است.
